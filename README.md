# 📱 Daily Routine Planner

**An Islamic-centered habit tracking and routine management system built with React Native**

---

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start the development server
npx expo start
```

## 🕌 About This App

The Daily Routine Planner is a comprehensive Islamic-centered mobile application designed to help Muslims balance spiritual growth, professional commitments, and family relationships through structured habit tracking and routine management.

### **Core Features**
- **🕌 5 Daily Prayers** with quality tracking and Islamic context
- **📖 Quran Recitation** sessions (Arabic + translation)
- **🤲 Zikr Management** with authentic Islamic dhikr
- **👨‍👩‍👧‍👦 Family-First Approach** balancing work and family time
- **📊 32-Point Discipline System** for comprehensive daily tracking
- **🔥 Streak Management** with Islamic milestone celebrations

## 🛠️ Technology Stack

- **Framework**: React Native 0.73.6 with Expo SDK 50
- **State Management**: Redux Toolkit + Redux Persist
- **Navigation**: React Navigation (Stack + Bottom Tabs + Drawer)
- **UI Components**: React Native Paper (Material Design)
- **Charts**: React Native Chart Kit
- **Storage**: AsyncStorage for persistence
- **Language**: TypeScript with strict type safety

## 📱 App Architecture

```
daily_routine_planner/
├── src/
│   ├── components/          # UI Components (Atomic Design)
│   │   ├── atoms/           # Basic building blocks
│   │   ├── molecules/       # Simple combinations
│   │   └── organisms/       # Complex compositions
│   ├── screens/             # Screen-level components
│   ├── navigation/          # Navigation configuration
│   ├── store/               # Redux state management
│   ├── constants/           # Design system & enums
│   ├── utils/               # Helper functions
│   ├── models/              # TypeScript interfaces
│   └── types/               # Type definitions
├── docs/                    # 📚 Complete documentation
└── assets/                  # Static assets
```
